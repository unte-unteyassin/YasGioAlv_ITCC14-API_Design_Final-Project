**Project Status:**
This repository contains the current frontend implementation progress.

We are using React (Vite) frontend for the XU EcoLab. 

**INSTRUCTIONS FOR RUNNING THE CURRENT FRONTEND:**
1. Install node.js
2. `npm install`
3. `npm run dev`

Routing uses `HashRouter`, so it deploys to any static host without rewrite rules

Plans for backend use: **Express** or **Flask**.
